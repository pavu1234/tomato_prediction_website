LEAF FLIGHT — CAMERA MONITOR FRONTEND UPDATE

For: https://github.com/pavu1234/tomato_prediction_website

1. Extract this ZIP on your computer.
2. Open your GitHub repository and select Add file > Upload files.
3. Upload index.html, drone.css and drone-ui.js into the repository root, replacing the existing versions. Upload the individual files, not the ZIP or an enclosing folder.
4. Select Commit changes. Wait for the GitHub Pages deployment to finish.
5. Open https://pavu1234.github.io/tomato_prediction_website/ and refresh. If it still shows the previous layout, use a private window or hard refresh.

This update reuses your existing drone.png, app.js, camera.js, engine.js, TFJS/TFLite files and tomato.tflite. Keep those files in place. No model, preprocessing or prediction engine changes are included.

Use Drone ON and allow camera permission. Frame one close-up tomato leaf, choose Capture image, then Analyze leaf. Drone OFF releases the camera. Upload leaf photo also remains available. The six most recent image thumbnails and their results remain in this tab only.

Inspired by the camera view and snapshot workflow in Paulooh007/drone-based-plant-monitoring-system. No reference images or code were copied. This frontend displays whole-image leaf classification, not YOLO crop detection, tracking, plant counts or lesion localization. Result labels are hidden over live video to avoid presenting an earlier captured result as live detection.

Verification: JavaScript syntax, original element IDs, mocked camera lifecycle, gallery size limit, result association, live-video result isolation and plain-text mission inputs passed. Real camera permissions and browser visual rendering were not verified in this environment. UI changes do not establish improved model accuracy.
