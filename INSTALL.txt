MULTI-DRONE CAMERA UPDATE — LEAF FLIGHT

This is an update for your existing tomato_prediction_website, not a replacement trained model.

1. Extract the ZIP.
2. Open https://github.com/pavu1234/tomato_prediction_website
3. Select Add file > Upload files.
4. Upload these files to the repository ROOT (not inside a new folder):
   index.html
   drone.css
   drone-ui.js
   camera.js
   whep-camera.js
   CAMERA_SETUP.md
   drone.png
5. Commit changes and wait for GitHub Pages to deploy. Refresh your website.

Keep your existing app.js, engine.js, tf.min.js, tflite_web_api_cc.js,
tflite_web_api_cc.wasm and tomato.tflite in place. They are not replaced here.
The adapter/ folder is for your ground-station computer, not GitHub Pages.

On the website choose the camera connection BEFORE Drone ON:
- Phone / laptop: allow permission, capture a leaf, then Analyze leaf.
- Connected capture device: refresh, explicitly select your receiver/capture device, then Drone ON.
- Network adapter: follow CAMERA_SETUP.md first; enter its HTTPS WHEP endpoint.

Drone ON/OFF controls the VIDEO CONNECTION ONLY. It does not operate drone motors or power.
No physical drone or streaming adapter was available for end-to-end testing.
